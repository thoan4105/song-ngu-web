      Chưa đồng bộ

      Đồng bộ qua repo GitHub
      1. Tạo một repo private để chứa dữ liệu, ví dụ song-ngu-data, tại github.com/new. Tick “Add a README file” để repo có sẵn nhánh main.
      2. Tạo token tại Settings → Developer settings → Fine-grained tokens. Repository access: Only select repositories, chọn đúng repo dữ liệu. Permissions → Repository permissions → Contents: Read and write.
      3. Dán vào đây. Mỗi máy làm bước này một lần; token chỉ lưu trong trình duyệt của máy đó.
